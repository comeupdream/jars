# JARSAMP music

Drop `.mp3` files here, then list them in `js/content.js` under `music: [ ... ]`:

```js
music: [
  { title: "Track Name — Artist", src: "assets/music/track1.mp3" },
  { title: "Another One",          src: "assets/music/track2.mp3" },
],
```

Need to make an mp3 from a video/YouTube link? Use the helper in `tools/`
(`tools/yt2mp3.ps1` on Windows, `tools/yt2mp3.sh` on macOS/Linux).

⚠️ Only add audio you own or are licensed to use.
